## 公开版范围

已收录 Brazil YOLO11、Self-Driving Cars 416 镜像和 GTSDB 第三方整理版的原始 ZIP；它们采用 Git LFS 存储。克隆后执行 `git lfs pull`，再按需解压相应 ZIP。每份数据的来源、许可与版本差异见各目录说明。使用数据时请保留原作者署名，并引用原项目。

CCTSDB2021、TT100K 等数据通过原作者或发布平台链接获取。论文原文 PDF、中文译文、翻译过程文件以及来源权属尚未确认的中文稿没有放入这个公开仓库；论文链接已列在清单中。

LLVIP 原始包及论文 PDF 只保存在本地，不上传公开仓库。这里提供可复现的数据准备与训练脚本、原始下载入口和核验记录。尚未产生 LLVIP 的训练权重或实测精度。各数据集的类别与划分不同，实验前请阅读核验记录。
