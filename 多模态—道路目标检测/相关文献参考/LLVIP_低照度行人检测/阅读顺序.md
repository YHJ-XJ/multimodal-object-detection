# LLVIP 低照度行人检测阅读顺序

1. `01_LLVIP_ICCVW2021_原始数据集论文.pdf`：了解数据采集、严格配对、行人标注和低照度困难。作者页面：https://bupt-ai-cz.github.io/LLVIP/
2. `02_CSSA_CVPRW2023_RGB_IR_Fusion.pdf`：轻量化通道切换＋空间注意力，在 LLVIP 与 FLIR 上验证融合收益。论文：https://openaccess.thecvf.com/content/CVPR2023W/PBVS/papers/Cao_Multimodal_Object_Detection_by_Channel_Switching_and_Spatial_Attention_CVPRW_2023_paper.pdf
3. `03_WaveMamba_ICCV2025_RGB_IR_Detection.pdf`：看 RGB 与红外融合检测的现代方法，以及 LLVIP 上的实验协议。论文：https://openaccess.thecvf.com/content/ICCV2025/papers/Zhu_WaveMamba_Wavelet-Driven_Mamba_Fusion_for_RGB-Infrared_Object_Detection_ICCV_2025_paper.pdf
4. `04_PedDet_2025_Multispectral_Pedestrian.pdf`：专门的多光谱行人检测，包含 LLVIP 实验。预印本：https://arxiv.org/abs/2502.14063
5. `05_GM_DETR_CVPRW2024_RGB_IR_Detection.pdf`：双模态 DETR 与更广泛的 RGB/IR 数据使用方式，在 LLVIP 上报告结果。论文：https://openaccess.thecvf.com/content/CVPR2024W/JRDB/papers/Xiao_GM-DETR_Generalized_Muiltispectral_DEtection_TRansformer_with_Efficient_Fusion_Encoder_for_CVPRW_2024_paper.pdf
6. MCFusion（Algorithms 2026）：基于 YOLO11n 的轻量 RGB-T 行人检测，报告 LLVIP 上 RGB 基线、直接融合和特征融合的对照。全文：https://www.mdpi.com/1999-4893/19/6/468 。网站目前对自动 PDF 下载返回 403，故先保留合法开放的全文链接，不把不完整文件当成已下载论文。

推荐先复现 RGB、热红外和四通道早期融合三组，再读 MCFusion 的双分支特征融合。论文中的 mAP 与本项目结果只有在数据版本、官方测试集、图像尺寸、模型、训练轮数和评价阈值一致时才具有可比性。
