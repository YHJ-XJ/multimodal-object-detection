# LLVIP 数据来源与核验

- 数据集：LLVIP，RGB 可见光＋热红外配对，目标类别 `person`
- 原作者项目：https://github.com/bupt-ai-cz/LLVIP
- 原作者下载页：https://github.com/bupt-ai-cz/LLVIP/blob/main/download_dataset.md
- 原作者许可：https://github.com/bupt-ai-cz/LLVIP/blob/main/Term%20of%20Use%20and%20License.md
- 官方 Google Drive 文件 ID：`1VTlT3Y7e1h-Zsne4zahjx5q0TK2ClMVv`，当前触发下载限流
- 官方百度网盘：https://pan.baidu.com/s/1eQO1Is2NPyd-mgmv1Csbfg ，提取码 `14lc`
- 本地压缩包获取源：https://huggingface.co/datasets/McCheng/LLVIP/resolve/main/LLVIP.zip
- Hugging Face 仓库标称大小：`4,003,858,172` 字节；该镜像不是原作者发布入口
- Hugging Face 文件元数据给出的 SHA256：`b3b55475c093ac54663c467859eb31a82b840b53a7196ad1887cb547e4518b45`；本地压缩包散列与之相同。另一个公开镜像列出相同散列，只能证明两镜像文件相同，不能替代原作者版本核对。
- 用途：本机非商业科研；原始图像与标注不上传公开 GitHub
- `基线准备_可训练` 是指向 `D:\rgbt_data\LLVIP_prepared` 的本机目录联接，用于存放较大的转换结果；四通道 TIFF 必须通过这个纯英文的实际路径交给 OpenCV。旧目录联接 `基线准备` 未用于正式训练。公开仓库只记录路径说明，不上传该目录的图片。

`split_manifest.csv` 的 SHA256 为 `088b02a8a23b574a5a5f5900a83a8782080f20b53d48bfef42f2362b318de572`。验证集占作者训练集的 13.2%，按两位文件名前缀整组划分；实际比例略低于设定的 15%，避免一个 1,313 对的大组导致过度划出训练样本。数据已通过本地格式核验，但该镜像与原作者官方包是否逐字节相同尚未由官方 SHA256 证明。

零宽度框分别位于 `020118`、`020236`、`090437`、`091180`、`170350`。本地审计脚本为 `基线代码/audit_llvip_annotations.py`。保持其余有效标注不变，不人为扩展为宽 1 像素的框。

`D:\rgbt_env` 的 PyTorch 为 CPU 版；30 对样本完成了 1 轮四通道训练、验证和测试试跑，模型第一层确认为 4 通道。完整 GPU 训练及其准确率尚未产生。
