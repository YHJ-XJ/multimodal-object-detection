# 巴西道路标识 YOLO11 数据集

- 发布页：https://doi.org/10.5281/zenodo.17900512
- 发布者：巴西圣保罗州立大学（Unesp）相关研究团队，2026 年，版本 15。
- 发布平台记录：开放获取，CC BY 4.0；原始标注与图像来自自行采集及多个 Roboflow 数据集，随后做了数据增强。
- 本地原始包：`lunarsigndetect.v15-novo-corrigido.yolov11.zip`，270,964,294 字节；发布页 MD5 与本地实测均为 `1c3d0f2ba3d2e7647f9f9d475fedf5e8`；ZIP CRC 全部通过。
- 解压内容：`dataset/`；保留发布包中的 `data.yaml`、`README.dataset.txt` 和 `README.roboflow.txt`。
- 训练配置：使用本目录的 `data_local.yaml`。原始 `dataset/data.yaml` 的路径相对于当前存放位置不正确，故另存本地配置，不修改原始文件。

六类分别为 R-25a、R-25b、R-26、R-3、R-4a、R-4b。全部图像可读取；图像与标注一一配对；全部 2444 个 YOLO 框的类别、数值范围和边界均通过检查；未发现训练/验证/测试之间的完全相同图像。原图尺寸并不统一，实际检查到 195 种尺寸，训练时应统一设置输入尺寸。

本数据集只有巴西道路标识的六个细类，且样本分布不均衡。它可用于小范围迁移或鲁棒性试验，不能将其 mAP 与当前论文 15 类数据或 CCTSDB2021 直接横向比较。由于发布包包含增强图，跨划分未发现完全相同的图片不代表不存在同一原图的不同增强版本；正式评测前建议按原图来源复核潜在数据泄漏。
